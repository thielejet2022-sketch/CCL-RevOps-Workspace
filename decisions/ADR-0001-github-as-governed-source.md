# ADR-0001 — GitHub as Governed Source of Truth

**Date:** 2026-10-07
**Status:** ACCEPTED

## Decision
Use this GitHub repository as the governed source of truth for durable CCL RevOps frameworks, schemas, definitions, decisions, and canonical state/handoff.

## Context
The work may need to persist across a transition from candidate-stage preparation into an operating role. Narrative research and collaboration may live elsewhere, but core operating definitions require version history and explicit change discipline.

## Consequences
- `CURRENT.md` becomes the canonical handoff.
- Durable definitions and schemas belong here.
- Notion can reference or explain governed artifacts rather than becoming the sole authority for them.
- CCL-specific assertions retain evidence status until validated.

# Signal Intelligence Engine — CCL

## Charter
The Signal Intelligence Engine (SIE) is a proposed RevOps framework for converting commercial and operational observations into governed, actionable signals.

It is not simply a dashboard. The intended loop is:

**Source → Signal → Context → Interpretation → Decision → Action → Outcome → Learning**

## Candidate-stage problem statement
Based on interview-stage work, CCL may have meaningful revenue intelligence distributed across functions rather than consistently converted into shared, timely action.

Potential signal domains include Sales/pipeline, Marketing/demand, existing accounts/expansion, Finance/commercial timing, delivery/capacity, customer/account engagement, and data quality/process compliance. These domains are provisional until validated.

## MVP objective
Create a Signal Taxonomy v0.1 that can answer, for each signal: What happened? Where did the evidence originate? Which entity does it concern? Why does it matter? How confident are we? What action should follow? Who owns that action? How will we know whether the intervention worked?

See `schemas/signals/signal-schema-v0.1.md`.
